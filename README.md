# SANA – Saudi Air Navigation AI

SANA is an AI-powered employee support platform developed during FIKRATHON in collaboration with Saudi Air Navigation Services (SANS).

The platform unifies employee services into one intelligent system through:
- Bilingual AI Chatbot (Arabic & English)
- Smart Ticketing System
- Employee & Admin Dashboards
- AI-powered Recommendations
- RAG-based Policy Retrieval

## Features

- Semantic policy question answering using RAG
- Smart ticket classification and recommendations
- Real-time employee support dashboard
- Conversation memory and bilingual support
- Integration with SharePoint & Power Automate
- AI-assisted workflow automation

## Technologies Used

- Python
- FastAPI
- React + Vite
- LangChain
- FAISS
- OpenAI GPT-4o
- Pandas
- MongoDB
- Recharts

## System Architecture

SANA combines:
- RAG-based chatbot
- Employee data analysis
- Ticket recommendation engine
- Real-time dashboards
into one unified AI employee platform.

## Project Impact

- Reduced employee search time
- Improved HR workflow efficiency
- Faster access to policies and information
- Unified disconnected internal systems
